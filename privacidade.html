Política de Privacidade

Última atualização: 19 de setembro de 2026.

Dados de navegação

Este site utiliza o Microsoft Clarity para entender como as páginas são utilizadas e melhorar a experiência de navegação. Quando o visitante aceita os cookies de análise, o serviço pode registrar informações técnicas e de interação, como tipo de dispositivo e navegador, páginas visitadas, interações, duração da sessão e localização aproximada.

Finalidade

Essas informações são utilizadas exclusivamente para analisar o funcionamento e a usabilidade do portfólio. Este site não possui cadastro, área de login, vendas ou formulário que envie os dados digitados para um servidor.

Serviço de terceiros

O tratamento realizado pelo Microsoft Clarity também está sujeito à Declaração de Privacidade da Microsoft.

Contato

Para dúvidas relacionadas à privacidade ou aos dados de navegação, escreva para inforf@hotmail.com.
